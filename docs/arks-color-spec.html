Design Language Color Spec

Six palettes. Four are house languages offered on every build; two are working variants for accessibility, client choice, and off-label fun. Every swatch is a flattened solid hex — translucent tokens have already been composited over their own background, so these paste straight into another project, Figma, or Power Apps without recreating the layering.

Chart Series

Sharedidentical in every language

Validated once for color-vision deficiency: worst adjacent-pair ΔE 10.7 in OKLab against a target of 8, passing in both light and dark. Never re-tint these per theme — there is no way to tell by eye that you have broken it. Assign in fixed order, never cycled. Kept as-is across every language, including the newest ones.

Rules that hold across every language

  • Status colors are reserved — never a chart series, never decoration.
  • Status is never color alone — always color + icon + word.
  • Charts sit on the chart plate, never directly on a panel.
  • Nothing is hard-coded. If a color appears twice, it is a token.
  • A new language inherits these rules on day one, draft or not.
